# MERYPLAST - Soluciones en Inyección y Soplado de Plásticos

Sitio web corporativo y catálogo digital para MERYPLAST. Especialistas en inyección de piezas técnicas y soplado de envases plásticos de alta precisión (PEAD, PET, PP).

## Estructura del Proyecto
- `index.html`: Página principal con Tailwind CSS y componentes interactivos.
- `assets/`: Logotipos e identidad visual corporativa.

Desarrollado para despliegue automatizado en Hostinger.
